## 关于我

你好，我是 **type_云**，在 GitHub 上记录自己的前端实验、小工具与完整项目。

我喜欢把抽象的念头做成能点开、能运行、能继续改的东西：有时是一套诗词社区界面，有时是一个浏览器里的 3D 场景，有时是给 AI 画图流程补上一块工具链。这里的大多数公开仓库，都是这样慢慢长出来的。
