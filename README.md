## flowli（type_云）

做前端和本地 AI 工具。项目大多围绕可本地运行、可检查的交互：画布、验收报告、数据协议，以及中文古诗词前端。

[Blog](https://2648782102.github.io/flowli-blog/) · [GitHub](https://github.com/2648782102?tab=repositories)

## 精选项目

### [Doodle](https://github.com/2648782102/Doodle)

人和 AI 共用的本地无限画布。人在画布上画图、连线和留言，AI 通过 MCP 读取画布并把回应画回同一张图。

[项目说明](https://github.com/2648782102/Doodle#readme) · [产品方向](https://github.com/2648782102/Doodle/blob/master/docs/PRODUCT_DIRECTION.md) · [架构](https://github.com/2648782102/Doodle/blob/master/docs/ARCHITECTURE.md) · [License](https://github.com/2648782102/Doodle/blob/master/LICENSE)

### [Proofpack](https://github.com/2648782102/proofpack-cli)

给 AI 辅助改动生成一份本地只读验收报告：记录 Git 能看到的变更、显式执行过的检查，以及还没检查的部分。提供 CLI 与 MCP，不替代码下「可以合并」的结论。

[项目说明](https://github.com/2648782102/proofpack-cli#readme) · [MCP 协议](https://github.com/2648782102/proofpack-cli/blob/main/docs/MCP.md) · [发布记录](https://github.com/2648782102/proofpack-cli/releases)

### [LanZe](https://github.com/2648782102/LanZe)

一个可本地运行的中文古诗词前端：Vue 3 + Vite，收录离线馆藏、读诗、检索、收藏、写作台与本地声景。始于 2022 年，2026 年整理为带文档、测试和 CI 的开源前端仓库。

[静态预览](https://2648782102.github.io/LanZe/) · [项目说明](https://github.com/2648782102/LanZe/blob/main/README.md#快速开始) · [设计系统](https://github.com/2648782102/LanZe/blob/main/docs/DESIGN_SYSTEM.md) · [FAQ](https://github.com/2648782102/LanZe/blob/main/docs/FAQ.md)
