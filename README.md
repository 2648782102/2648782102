## 正在做的项目

### [Doodle](https://github.com/2648782102/Doodle)

一张人和 AI 共用的本地无限画布。人在画布上画对象、箭头和短留言；AI 通过 MCP 读取画布，再把便签、形状和回应画回同一张图。
